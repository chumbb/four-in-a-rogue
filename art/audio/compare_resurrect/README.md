# Resurrect sound options (2026-11-23)

Plays when Occult (and any later "bring back" effect) raises a destroyed Goob: while it rises out of the Goob and arcs over the board (~0.7 s), before its normal drop + land. Built by `art/audio/make_resurrect_options.py`. Nothing is wired in until Sean picks.

| File | Idea |
|---|---|
| `A_ghost_rise.ogg` | Soft breathy swell rising, faint ghostly hum underneath, gentle hollow "pop" as it's back (airy, a bit spooky) |
| `B_unearthed.ogg` | Low earthy rumble + gritty scrape like being dug up, rising into a dull wooden "thunk" (heavier, physical) |
| `C_reverse_bell.ogg` | A bell played backwards: glassy shimmer swells up and stops dead on a soft pluck (eerie, magical) |
